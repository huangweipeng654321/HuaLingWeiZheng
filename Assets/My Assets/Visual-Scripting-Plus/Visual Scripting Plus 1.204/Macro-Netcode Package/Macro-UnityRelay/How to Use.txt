To use Relay : you need to install both plugin Netcode & Relay

1.*** Must install plugin "Netcode for Gameobjects" : 1.6.0 to work with : (newer versions might work too)
- Install from package name : 
line 1 (name) : com.unity.netcode.gameobjects
line 2 (version) : 1.6.0

2.*** Must install plugin "Relay" : 1.0.5 to work with : (newer versions might work too)
- Install from package name : 
line 1 (name) : com.unity.services.relay
line 2 (version) : 1.0.5


3. Unzip file  [Macro-Netcode][Macro-UnityRelay] > Restart Unity Editor (Must) > Then Use as other Macro.
