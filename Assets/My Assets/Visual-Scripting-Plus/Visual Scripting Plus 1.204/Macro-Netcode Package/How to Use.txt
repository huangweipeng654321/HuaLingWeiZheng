1. To use Macro-Netcode :
 *** Must install plugin "Netcode for Gameobjects" : 1.6.0 to work with : (newer versions might work too)
- Install from package name : 
line 1 (name) : com.unity.netcode.gameobjects
line 2 (version) : 1.6.0

2.To use Macro-UnityRelay :
*** Must install plugin "Relay" : 1.0.5 to work with : (newer versions might work too)
- Install from package name : 
line 1 (name) : com.unity.services.relay
line 2 (version) : 1.0.5

3. To use Macro-UnityLobby :
*** Must install plugin "Lobby" : 1.1.2 to work with : (newer versions might work too)
- Install from package name : 
line 1 (name) : com.unity.services.lobby
line 2 (version) : 1.1.2

4. Unzip file you need [Macro-Netcode][Macro-UnityRelay][Macro-UnityLobby] > Restart (must) > Ready to use.
